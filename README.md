Stock Price Prediction (Short-Term)
Objective

Predict the next-day closing price of Apple stock using historical OHLCV data.

Dataset

Historical Apple (AAPL) stock data from Yahoo Finance.

Models Used

Linear Regression

Random Forest Regression

Results
Model	MAE	RMSE
Linear Regression	2.35	3.12
Random Forest	1.85	2.45
Tools

Python, Pandas, Scikit-Learn, Matplotlib, Seaborn, yfinance

Conclusion

Random Forest performed better. Predictions closely match actual prices, showing OHLCV data works well for short-term stock forecasting.
